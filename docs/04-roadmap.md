## Phase 1 — 하드웨어 브링업 ✅ 완료 (2026-09-16)

> 펌웨어는 작성·컴파일 완료. 아래 항목은 전부 **실기 검증** 항목이므로
> 부품이 도착해야 체크할 수 있다. 절차는 [../firmware/README.md](../firmware/README.md).

- [x] PlatformIO 프로젝트 생성, 빌드 파이프라인 (`pio run` 성공)
- [x] 업로드 확인 (pyOCD, 2026-09-15)
- [x] 모터 양방향 구동 + PWM 속도 제어
- [x] 엔코더 카운트 읽기 → 실제 이동거리(mm) 환산
- [x] ToF 3개 동시 동작 (I2C 주소 재할당)
- [x] IMU 읽기
- [x] 고정 주기 50 Hz 루프 (지터 측정해서 기록)

**완료 조건**: 1 m 직진 명령 시 실측 오차 ±5 % 이내.
루프 주기 지터가 50 Hz 기준 ±2 ms 이내.

> 여기서 오도메트리가 부정확하면 3단계 보상이 통째로 거짓말이 된다.
> 대충 넘어가면 안 되는 유일한 단계.

## Phase 2 — 규칙 기반 자율주행 ✅ 부분 완료 (2026-09-17)

- [x] 규칙 기반 장애물 회피 (전진 / 회전 / 후진 상태 기계)
- [x] 스스로 포기하는 안전장치 (10초 무진전 · 180초 세션 상한) — 무선은 믿을 수 있는 정지 수단이 아니다
- [x] 벽 밀착 탈출: 세 거리값이 2초간 안 변하면 충돌로 간주
- [~] ~~범퍼 안전 정지~~ — **폐기.** 스위치만 있고 범퍼 프레임이 없어 물리적으로 눌리지 않는다
- [~] ~~자이로 방향 보정~~ — **삭제** (1 m당 우측 10 cm 휨은 알려진 한계로 둔다)
- [ ] 거리센서 10° 위로 기울이기 — **보류.** 지금은 센서가 바닥을 봐서 감지 거리가 13.5 cm뿐이다 (`hardware/bringup-log.md`)
- [ ] 시리얼 텔레메트리 스트리밍 (`host/`에서 그래프)

**완료 조건**: 명령 없이 10분간 방 안을 돌아다니며 충돌 3회 이하.

> **미달성으로 기록하고 넘어간다.** 범퍼가 없어 충돌을 셀 수단이 없고, 센서가 바닥을 봐서
> 벽에 자주 닿는다. 실측: 전진 7.5 s → 코너에 갇혀 자동 정지 (17 s), 이전 설정에서는 143 s 주행.
> 3단계 baseline은 "충돌 횟수" 대신 **엔코더 전진 거리와 자동 정지까지의 시간**으로 잡는다.

> **여기서 이미 "명령 없이 자율적으로 움직이는 로봇" 목표는 달성된다.**
> 자율성은 AI를 요구하지 않는다. 이 사실을 확인하고 넘어가야
> 3단계에서 "AI가 뭘 더해줬는지"를 정직하게 평가할 수 있다.
> 2단계 성능이 3단계 비교 기준선(baseline)이 된다.

## Phase 3 — 온디바이스 Q-learning ★ 프로젝트의 핵심 ← **현재**

- [x] 상태 이산화 — 전방 3구간 × 측면 3구간 × 직전 행동 4 = 36 상태
- [x] Q 테이블 + ε-greedy 탐험 (0.30 → 0.05, 스텝마다 ×0.999, 테이블과 함께 저장)
- [x] 보상 함수 초안 — 엔코더 전진 1 m당 +30, 회전 −0.1, 너무 가까움 −1, 접촉 −10
- [x] EEPROM 체크포인트 → **재부팅 후 유지 확인** (85스텝·ε 0.276 그대로 복원)
- [x] 호스트 학습 곡선 — 대시보드 Wi-Fi 연결 시 구간 평균 보상을 실시간으로 그림
- [x] 학습기 단위 테스트 20개 (`pio test -e native`)
- [ ] **바닥 학습 주행** — 아직 한 번도 못 함
- [ ] 규칙 기반(`a`)과 같은 조건에서 비교 (전진 거리 · 접촉 · 탈출 횟수)

**완료 조건**:
1. 학습 곡선이 우상향하고, 서로 다른 시드 3회에서 재현된다.
2. 학습 후 성능이 **2단계 규칙 기반 baseline을 넘는다.**
3. 전원을 껐다 켜도 학습된 행동이 유지된다.

> 2번이 진짜 관문이다. 넘지 못하면 "학습은 했지만 손으로 짠 규칙보다 못한"
> 상태인데, 그것도 정직한 결과다. 그 경우 상태 표현이나 보상 설계를 의심한다.

## Phase 4 — TinyML 추론 (선택)

- [ ] Edge Impulse 또는 TFLite Micro 파이프라인 구축

- [ ] PPO로 정책 학습

## 중단 지점

**3단계까지가 이 프로젝트의 본체다.** 4·5단계는 흥미가 남아 있으면 간다.
3단계를 제대로 끝내면 "동작을 학습하고 명령 없이 자율적으로 움직이는 로봇"이
실제로 손에 있다. 그게 원래 목표였다.
