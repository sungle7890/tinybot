# 조립·배선 가이드 — UNO R4 WiFi + Romi

> English: [assembly_eng.md](assembly_eng.md)

핀 번호의 원천은 `firmware/include/pins_r4.h`. 이 문서와 어긋나면 코드가 맞다.

**단계를 건너뛰지 말 것.** 각 단계는 앞 단계가 검증됐다는 전제 위에 있다.
문제가 생겼을 때 "어느 단계에서 깨졌나"를 좁히는 게 이 순서의 목적이다.

## 공통 안전 규칙

- 배선을 바꿀 때는 **항상 전원 OFF** (USB 뽑기, #3541 버튼으로 끄기)
- **Qwiic은 3.3 V 전용.** 5 V를 넣으면 R4가 망가진다
- 탄내·뜨거운 부품·R4 LED 꺼짐 → 즉시 #3541 버튼으로 전원 차단
- 모터 첫 구동은 **바퀴를 공중에 띄운 상태**로

## 1단계 — 센서만 (USB 전원, 배터리·모터 없음)

### 납땜 — 거리센서(VL53L0X)에 헤더 핀 달기

ToF 거리센서(VL53L0X · Adafruit 3317) 가장자리의 구멍 7개에 헤더 핀(검은 플라스틱
막대에 금속 핀이 박힌 부품)을 납땜한다. 그래야 `XSHUT` 핀에 점퍼선을 꽂을 수 있다.
3개 모두 같은 작업. 6축 관성 센서(MPU-6050)는 Qwiic만 쓰므로 납땜하지 않는다.
그림이 있는 버전은 조립 매뉴얼 페이지를 볼 것.

- **방향**: 플라스틱은 보드 **아래**, 짧은 핀 끝이 보드 **위로** 올라오게. 레이저 창이 있는 면이 위. 긴 쪽은 아래로 향해 점퍼선 꽂는 곳이 된다
- **고정**: 헤더 긴 쪽을 브레드보드에 꽂고 그 위에 보드를 얹는다 (없으면 마스킹테이프)
- **인두**: 유연 약 330~350 °C, 무연 약 350~380 °C. 팁을 닦고 시작

1. 한쪽 끝 핀 하나만 납땜 — 인두 끝을 **핀과 패드에 동시에** 1~2초, 반대쪽에서 땜납을 이음부에 대고, 땜납 → 인두 순으로 뗀다
2. 헤더가 직각인지 확인. 기울었으면 그 핀을 다시 녹이며 바로잡는다
3. 반대쪽 끝 → 가운데 4개
4. 6개 모두 반짝이는 작은 원뿔이고 옆 핀과 붙지 않았는지 확인
5. 보드를 곧게 위로 뽑는다

⚠️ 한 핀을 3초 넘게 데우지 말 것(패드가 떨어진다). 레이저 창에 땜납·플럭스가 튀지
않게. 헤더가 동봉됐는지는 확인하지 못했다 — 없으면 헤더핀 스트립(2.54 mm)을 6핀으로
잘라 쓴다.

**점퍼선**: 수-암(M-F). 암 끝을 센서 `XSHUT`에, 수 끝을 R4 A0/A1/A2에. 나머지 5핀은 비운다.

**핀 이름**: 받은 보드(2020년 7월 이후 STEMMA QT 개정판)의 6핀은 `VIN` `GND` `SCL` `SDA` `GPIO` `XSHUT`.
`GP10`처럼 보이는 핀은 `GPIO`(알파벳 O)이고 쓰지 않는다. 구버전 문서는 이 핀을 `SHDN`, 핀 7개(`2v8` 포함)로
적지만 Adafruit에 따르면 회로는 같다. `XSHUT`은 보드에서 HIGH로 풀업되어 있고 레벨 변환 다이오드가 있어
R4의 5 V로 직접 구동해도 안전하다. 보드의 `3-5V` 인쇄가 그 뜻이다. 이 개정판은 STEMMA QT 커넥터가 2개라 체인이 된다.

### 배선

| 연결 | 방법 |
|---|---|
| R4 Qwiic → VL53L0X → VL53L0X → VL53L0X → MPU-6050 | QT to QT 케이블 체인 |
| **전방** VL53L0X `XSHUT` → R4 **A0** | 점퍼선 |
| **좌** VL53L0X `XSHUT` → R4 **A1** | 점퍼선 |
| **우** VL53L0X `XSHUT` → R4 **A2** | 점퍼선 |

체인 순서는 전기적으로 상관없다. 주소는 체인 위치가 아니라 **XSHUT 순서**로
정해진다. 대신 **센서마다 전방/좌/우 라벨을 붙여둘 것** — 나중에 섞이면 찾기 어렵다.

### 검증
```bash
cd firmware
pio run -t upload
pio device monitor
```
기대 출력:
```
bring-up: 3/3 ToF, IMU ok
```
그다음 `t`(손을 대면 거리값 변화), `i`(보드를 기울이면 accel 변화, 툭 치면 shock).

| 증상 | 의심할 곳 |
|---|---|
| `0/3 ToF`, IMU MISSING | Qwiic 체인 전체. 케이블이 끝까지 꽂혔나 |
| `0/3 ToF`, IMU ok | 3개 모두 XSHUT 배선. 또는 A0가 LOW로 붙어 있음 |
| `1/3`, `2/3` | 빠진 센서의 XSHUT 선 |
| ToF 값이 8190 고정 | 정상 — 범위 밖. 손을 20 cm 안으로 |

**통과 조건: `3/3 ToF, IMU ok`, 세 센서 모두 손에 반응.**

## 2단계 — 모터·인코더 조립 (전원 없음)

### 인코더 보드 납땜 (좌우 각각)
1. 인코더 보드를 모터 뒤쪽 **두 단자에 직접** 끼운다
2. **한 핀만 먼저 살짝 납땜**(tack) → 보드가 평평하게 정렬됐는지 확인 → 나머지 핀 납땜
3. ⚠️ **모터 핀을 오래 가열하지 말 것.** 모터 케이스나 브러시가 변형된다 (Pololu 경고)

### 자석 디스크
디스크를 평평한 곳에 놓고, **모터를 위에서 눌러** 축 끝이 바닥에 닿을 때까지 밀어 넣는다.

### 인코더 보드 6핀
`M1` `M2` `VCC` `GND` `A` `B` — 여기에 선이나 헤더를 납땜한다. **이 단계에서는 어디에도 연결하지 않는다.**

| 핀 | 좌측 엔코더 → | 우측 엔코더 → |
|---|---|---|
| `M1` | 모터 드라이버(TB6612FNG) `AO1` | 모터 드라이버(TB6612FNG) `BO1` |
| `M2` | 모터 드라이버(TB6612FNG) `AO2` | 모터 드라이버(TB6612FNG) `BO2` |
| `VCC` | R4 `5V` | R4 `5V` |
| `GND` | 공통 GND | 공통 GND |
| `A` | R4 `D2` | R4 `D3` |
| `B` | R4 `D4` | R4 `D12` |

`M1`/`M2`는 R4가 아니라 모터 드라이버로 간다. `AO1`의 가운데는 **알파벳 O**(Output)이고 R4의 `A0`와 무관하다.

> **⚠️ 인코더 사양 두 가지**
> - **VCC는 최소 3.5 V.** 3.3 V 레일로는 안 된다 → R4 **5 V**에 연결
> - **A/B는 오픈드레인 출력**이라 풀업이 필요하다. 펌웨어가 `INPUT_PULLUP`으로
>   R4 내부 풀업을 켜둔다. 카운트가 튀면 A/B 각각에 4.7~10 kΩ 외부 풀업(→5 V)을 단다

### 섀시에 모터 장착
Romi 키트의 모터 클립으로 고정. 바퀴 끼우기.

## 3단계 — 섀시 조립·전원 배선 (배터리 넣지 않음)

### 순서가 중요하다
1. **#3541 전원 보드를 먼저 섀시에 장착**
2. **그다음 배터리 접점 4개를 납땜** — Pololu 지침: 반드시 **장착 후**에 납땜
3. TB6612FNG, R4를 섀시에 고정 (스탠드오프 또는 양면 폼테이프.
   R4의 구멍이 Romi 섀시 구멍과 맞는지는 확인하지 못했다)

### 전체 연결표

**전원**

| 출발 | 도착 | 비고 |
|---|---|---|
| #3541 `VSW` | TB6612 `VM` | 모터 전원 (스위치·역전압 보호 후단) |
| #3541 `VSW` | R4 `VIN` | 로직 전원. R4가 5 V/3.3 V로 레귤레이션 |
| #3541 `GND` | 공통 GND | |
| R4 `5V` | TB6612 `VCC` | 드라이버 로직 |
| R4 `5V` | 좌·우 인코더 `VCC` | **3.3 V 아님** |
| R4 `GND` | 공통 GND | **모든 GND를 한 점으로** |

**모터 드라이버 제어**

| R4 | TB6612 |
|---|---|
| D5 | `PWMA` |
| D7 | `AIN1` |
| D8 | `AIN2` |
| D6 | `PWMB` |
| D9 | `BIN1` |
| D10 | `BIN2` |
| D11 | `STBY` |

**모터 출력**

| TB6612 | 인코더 보드 |
|---|---|
| `AO1`, `AO2` | **좌** `M1`, `M2` |
| `BO1`, `BO2` | **우** `M1`, `M2` |

**인코더 신호**

| 인코더 | R4 |
|---|---|
| 좌 `A` | **D2** (인터럽트) |
| 좌 `B` | D4 |
| 우 `A` | **D3** (인터럽트) |
| 우 `B` | D12 |

**범퍼** (Snap-action 스위치 3핀 중 `COM`과 `NO`만 사용)

| 스위치 | 연결 |
|---|---|
| 좌 `COM` | GND |
| 좌 `NO` | R4 **A3** |
| 우 `COM` | GND |
| 우 `NO` | R4 **A4** |

**센서** — 1단계 그대로.

### 커패시터 (권장)
TB6612 캐리어에는 이미 필터 커패시터가 있다. 그래도 Romi 모터 기동 전류 대비로
**1000 µF 전해 커패시터를 VM–GND에** 드라이버 가까이 단다.
⚠️ 전해 커패시터는 **극성이 있다.** 띠 표시(−)가 GND.

## 4단계 — 전원 투입 전 점검 (테스터기)

배터리를 넣기 **전에**, 전원 OFF 상태에서:

| 측정 | 기대값 | 아니면 |
|---|---|---|
| `VSW` ↔ `GND` 저항 | 수백 Ω 이상 (0 Ω 아님) | **단락. 배터리 넣지 말 것** |
| R4 `5V` ↔ `GND` 저항 | 0 Ω 아님 | 단락 |
| 인코더 `VCC`가 5V에 연결됐나 | 도통 | 재배선 |
| 배터리 방향 | 홀더 표시와 일치 | #3541에 역전압 보호가 있지만 믿지 말 것 |

NiMH 6개를 **완충해서** 넣는다. 이유는 아래 "알려진 한계" 참조.

## 5단계 — 첫 전원 (바퀴 공중)

1. 섀시를 상자 위에 올려 **바퀴가 뜨게**
2. #3541 버튼으로 전원 ON. R4 LED 확인
3. USB 연결, `pio device monitor`
4. `st` — 3/3 ToF, IMU ok, mode idle
5. `f 300` → **양쪽 바퀴가 전진 방향으로** 도는지. 반대면 그쪽 `M1`/`M2`를 바꾼다(코드 수정 금지)
6. `s` 정지

## 6단계 — 인코더 방향

`z` → 바퀴를 **손으로 전진 방향**으로 굴린다 → `e`.
**양쪽 다 증가**해야 한다. 하나가 줄면 그쪽 인코더 `A`/`B` 두 선을 바꾼다.

## 7단계 — Phase 1 관문

[firmware/README.md](../firmware/README.md)의 5·6번:
캘리브레이션(`d 1000` → 실측 → `cal`)과 지터(`jz` → `v` → 60초 → `j`).

## 알려진 한계

**배터리 말단 전압.** R4 VIN 최소 입력은 6 V다. NiMH 6개는 공칭 7.2 V지만
방전 말기에 셀당 1.0 V, 즉 **6.0 V까지** 떨어진다. 배터리가 거의 다 되면 R4가
리셋될 수 있다. 긴 실험 전에는 완충할 것.

Phase 3에서 학습 중 리셋되면 마지막 체크포인트 이후 학습이 사라진다. 예비 핀
**A5에 분압 저항으로 배터리 전압 모니터**를 달면 저전압에서 먼저 체크포인트를
저장하고 멈출 수 있다 — 필요해지면 추가한다.
